Marketing ChangeGuard: five product directions

Low-fidelity previews of five meaningfully different experiences for the same capability: a configuration change is preflighted, reviewed, approved by a different person, released into the synthetic environment and verified. Each is judged for a marketing operations user and a technical reviewer. The chosen direction is outlined.
